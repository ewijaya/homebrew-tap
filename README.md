# ewijaya/homebrew-tap

Homebrew formulae for [ewijaya](https://github.com/ewijaya)'s tools.

## Usage

```bash
brew install ewijaya/tap/lmtop
```

Or tap once, then install by name:

```bash
brew tap ewijaya/tap
brew install lmtop
```

## Formulae

| Formula | Description |
|---|---|
| [`lmtop`](https://github.com/ewijaya/lmtop) | Live terminal monitor for language-model usage, quotas, and subscription capacity |

Formulae here are generated by each project's release workflow — edits by
hand will be overwritten on the next release.
